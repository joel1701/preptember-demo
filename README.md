# COSC Preptember demo

Open index.html in your browser. No installation or build command needed.

Deploy on Vercel: import the repository, choose Other, keep the root directory at ./ and use default build settings.

For the recorded update, edit index.html:

- COSC presents Preptember → A Preptember session by COSC
- Deployment basics → Deployment basics: GitHub to Vercel

Save, then run:

```sh
git add .
git commit -m "update"
git push
```
